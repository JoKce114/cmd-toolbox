# v1.4.0 浏览器快捷键、移动端模拟与 AI 页签状态 实现计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 让浏览器页签支持 F5 刷新与移动端视口模拟，让 AI 终端页签在页签栏直接显示状态并标记「已完成未读」。

**Architecture:** 浏览器键盘与设备模拟都绕不开主进程——`<webview>` 收不到应用层快捷键，`enableDeviceEmulation` 也只在 `WebContents` 上。复用 `desktop/pane-api.js` 已有的 `guests`（tabId → webContentsId）映射，经 `panes:*` IPC 暴露。AI 状态继续用现有的输出启发式，只新增未读过渡状态并按页签、项目两级汇总。

**Tech Stack:** Electron 45、React 19、TypeScript 5.9、Vite 6、Playwright（驱动真实 Electron）

## Global Constraints

- 唯一版本号源头是 `package.json` 的 `version`，改完必须 `npm install --package-lock-only`
- IPC 新增通道必须四处同改：`desktop/main.js`、`desktop/preload.js`、`src/global.d.ts`、React 调用点
- IPC 通道命名沿用 `<模块>:<动作>`，本次是 `panes:emulate`、`panes:reload`
- 用户可见文案全部使用中文
- 所有 UI 测试必须独占运行，启动前先关掉正在运行的 Cmd Toolbox（端口 17382 冲突），并设置 `CMDTOOLBOX_NO_UPDATE=1`
- 改了 `src/` 之后先 `npx tsc --noEmit && npx vite build` 再跑 GUI 测试，不要用 `npm run build`
- 提交信息不加任何 AI 署名
- 设备模拟**不做**触摸事件模拟
- `.tab-lamp` 复用 `.group-lamp` 的四色语义，不要再定义一套颜色

### Task 0: 探针——确认移动端模拟的可行路径（已完成）

**结论（2026-10-30 实测）：`enableDeviceEmulation` 对 webview guest 不可用**，
视口会被缩放成 981×1744。改用纯前端方案：设置 `<webview>` 元素尺寸
（探针实测得到正确的 375×667）+ `view.setUserAgent()` 切 UA。**不需要新增 IPC。**

保留 `tests/device-emulation-probe.mjs` 作为回归测试。

### Task 1: 浏览器 F5 刷新

**Files:**
- Modify: `desktop/pane-api.js:544`（`attachBrowser`）
- Modify: `src/components/BrowserPane.tsx:164`（`onKeyDown`）

**Interfaces:**
- Produces: guest 上的刷新快捷键；应用层 `onKeyDown` 兜底

- [ ] **Step 1: 主进程挂 `before-input-event`**

在 `attachBrowser()` 里，取到 `webContents` 后挂监听。用 `guests` 里已有该 `tabId` 判断是否重复挂载。规则：`keyDown` + （`F5` 或 `Ctrl+R`）→ `preventDefault()` → `input.shift` 时 `reloadIgnoringCache()`，否则 `reload()`。

- [ ] **Step 2: 应用层兜底**

`BrowserPane` 的 `onKeyDown` 里，在现有 `Ctrl+F` 分支旁加 F5 / Ctrl+R / Ctrl+Shift+R，`preventDefault()` 后调 `viewRef.current?.reload()` / `reloadIgnoringCache()`。

- [ ] **Step 3: 验证焦点两种位置**

手动验证：焦点在地址栏按 F5 刷新；焦点在网页里按 F5 刷新。两条都要试。

### Task 5: AI 未读状态

**Files:**
- Modify: `src/sessionStatus.ts`
- Modify: `src/App.tsx:270-323`、`1264`

**Interfaces:**
- Produces:
  - `export type StatusTransition = 'set-unread' | 'clear-unread' | 'none'`
  - `export function transitionUnread(prev: ModelStatus | undefined, next: ModelStatus, watched: boolean): StatusTransition`
  - `export const IDLE_RESET_MS = 15000`

- [ ] **Step 1: 纯函数**

`transitionUnread` 按设计文档的规则表实现：忙碌→空闲/报错且未被观看 → `set-unread`；其余 → `none`。观看与否由调用方传入。

- [ ] **Step 2: App 接线**

`IDLE_RESET_MS` 替换 `App.tsx:293` 的 `8000`。新增 `unreadBySession` 状态：

- `subscribeAllData` 里检测到新输出 → 清除未读
- 状态迁移到 idle/error 时用 `transitionUnread` 判断，未观看则置位
- `selectTab` 后清除该页签的未读
- `tabsByGroup` 清理逻辑里同步清理未读

- [ ] **Step 3: 观看判定**

不能只看 `activeTabId`。左右分栏时两侧页签都算看过——用当前组左右两栏的页签 id 集合判断。

- [ ] **Step 4: 汇总到项目**

新增 `unreadByGroup`（任一会话未读即为真），与 `modelStatusByGroup` 同一个 `useMemo` 里算。
